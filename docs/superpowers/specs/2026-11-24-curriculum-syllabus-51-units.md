# Svenska Vägen — 51-Unit Curriculum Syllabus Reference (A0 → B2)

This syllabus maps every unit (`u01`–`u51`) to the grammatical progression of *Basic Swedish* (Units 1–25) and *Intermediate Swedish* (Units 1–26 + Diderichsen's Sentence Model).
